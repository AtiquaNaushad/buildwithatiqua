# buildwithatiqua (React + Vite)

## Run it
1. Install Node.js (LTS) from https://nodejs.org
2. In this folder: `npm install`
3. `npm run dev` then open the local link shown (http://localhost:5173)

## Build for hosting
`npm run build` creates a `dist/` folder. Upload it to Netlify or GitHub Pages.

## Edit
- Sections: `src/sections/*.jsx` (content arrays are at the top of each file)
- Styles and colors: `src/styles.css` (CSS variables at the top)
